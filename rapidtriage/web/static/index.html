이미지를 선택하면 지원 여부, 필요한 마운트/추출 도구, 파티션 선택, 해시/출처 기록을 먼저 확인한 뒤 분석으로 넘어갑니다.

1 이미지 선택 2 지원/도구 확인 3 파티션·마운트 4 분석/검색

새 분석

이미지 또는 추출 폴더 선택

대부분은 E01/Ex01 같은 이미지에서 시작합니다. 폴더만 있는 경우도 같은 칸에 넣으면 됩니다.

1 경로 입력 2 이미지 지원 확인 3 실행

분석할 E01/Ex01, 이미지, ZIP, 또는 폴더 경로를 먼저 입력하세요.

E01/Ex01/RAW/VHDX/DMG는 먼저 도구와 파티션 처리 가능 여부를 확인합니다.
고급 옵션 수집 대상, 제한값, E01 섹터, Known-good 설정

target collection

수집 대상 미리보기

큰 분석을 돌리기 전에 Windows/macOS 주요 아티팩트 경로가 있는지 먼저 확인합니다.

먼저 증거 경로를 넣은 뒤 수집 대상을 확인하세요.

file triage controls

Known-good suppression and extension spoofing checks

Use a TXT/CSV/JSON MD5/SHA1/SHA256 feed to mark normal files. Signature mismatch checks run automatically and appear in the Files tab.

케이스 큐

현재 케이스
분석 흐름과 첫 실행 팁 보기
1

입력

이미지/E01 선택과 지원 여부 확인 E01/Ex01, RAW, VHDX, DMG, ZIP, 폴더를 넣고 필요한 도구와 마운트/export 여부를 확인합니다.
2

추출

파일과 아티팩트를 해시와 함께 확보 manifest, file triage, bounded extraction으로 원본 경로, 크기, SHA256, 제한 사유를 보존합니다.
3

분석

OS·문서·메신저 아티팩트 파싱 EVTX, Registry, MFT/USN, Browser, AI, Mail, KakaoTalk 등 collector 결과와 warning을 확인합니다.
4

검색

전체 검색과 현재 파일 검색 본문, DB, 로그, OCR 후보를 찾고 cursor/resume 상태로 대량 누락을 확인합니다.
5

리뷰

원본 뷰어에서 확인하고 표시 원본 뷰어에서 경로, 해시, 파서, 오프셋을 확인하고 관련성, 메모, 태그를 남깁니다.
6

보고서

선택 증거를 제출 후보로 묶기 선별 보관함, 인용, 제한사항, 검증 상태를 보고 산출물에 연결합니다.
  1. 1. 이미지 선택E01/Ex01, RAW, VHDX, DMG 또는 마운트/Export 폴더를 넣습니다.
  2. 2. 지원 확인도구, 파티션, 마운트/export 필요 여부를 먼저 확인합니다.
  3. 3. 빠른 분석대용량은 Fast first pass로 먼저 범위를 좁힙니다.
  4. 4. 검색/보고서전체 검색 후 원본을 확인하고 보고서 후보를 남깁니다.

모드 선택 기준

문서·부정 조사가 가장 안전한 1차 분석입니다. 침해사고는 EVTX/실행 흔적, 복구는 삭제 단서, 전수 수집은 넓은 인벤토리에 사용하세요.

첫 실행 점검

  1. 환경 점검libewf/tsk/qemu-img 같은 이미지 처리 도구와 Python 패키지를 확인합니다.
  2. 이미지 지원 확인소스가 직접 스캔되는지, 마운트/export가 필요한지 확인합니다.
  3. 샘플 실행검색, 뷰어, 리뷰, 보고서 흐름을 안전하게 연습합니다.
  4. 빠르게 시작대용량 케이스는 먼저 빠른 1차 분석으로 범위를 좁힙니다.

새 케이스 시작

이미지 증거를 넣으면 분석 가능 여부부터 확인합니다.

E01/Ex01, RAW, VHDX, DMG, ZIP, 추출 폴더를 같은 흐름으로 받습니다. 이후 키워드 검색, 원본 검토, 증거 선별, 보고서 후보 정리까지 하나의 콘솔에서 이어집니다.

추천 진행

  1. 1. 접수원본 경로, 이미지 유형, 해시, dependency 상태 확인
  2. 2. 빠른 선별키워드, 최근/삭제, 위험도, OCR/문서 후보 좁히기
  3. 3. 원본 확인테이블 행을 source viewer, hex, SQLite, 문서 뷰어로 검증
  4. 4. 리뷰/보고서관련 있음, 재검토, 제외, 보고서 포함 상태 고정
키워드 선별사건 단어로 전체 자료를 3클릭 안에 좁힙니다.
아티팩트 검토EVTX, Registry, Browser, AI, USB, MFT/USN을 행위별로 봅니다.
문서 검토PDF/Office/text/메일/메신저/OCR 중심으로 선별합니다.
시간축 분석파일, 로그, 웹, 앱 흔적을 시간 흐름으로 연결합니다.
