확인 중
Read-only first Mass data aware Review-ready
1

입력

이미지/E01 선택과 지원 여부 확인 E01/Ex01, RAW, VHDX, DMG, ZIP, Folder를 넣고 dependency와 mount/export 필요 여부를 확인합니다.
2

추출

파일과 아티팩트를 해시와 함께 확보 manifest, file triage, bounded extraction으로 원본 경로, 크기, SHA256, 제한 사유를 보존합니다.
3

분석

OS·문서·메신저 아티팩트 파싱 EVTX, Registry, MFT/USN, Browser, AI, Mail, KakaoTalk 등 collector 결과와 warning을 확인합니다.
4

검색

전체 검색과 현재 파일 검색 본문, DB, 로그, OCR 후보를 찾고 cursor/resume 상태로 대량 누락을 확인합니다.
5

리뷰

원본 뷰어에서 확인하고 표시 source viewer에서 path/hash/parser/offset을 확인하고 relevant, note, tag를 남깁니다.
6

보고서

선택 증거를 제출 후보로 묶기 evidence tray, citation, limitation, validation 상태를 report bundle에 연결합니다.
  1. 1. 증거 선택폴더, 마운트 이미지, E01/파생 경로를 넣습니다.
  2. 2. 빠른 분석대용량은 Fast first pass로 먼저 범위를 좁힙니다.
  3. 3. 검색/뷰어전체 검색 후 원본 파일 안에서 다시 확인합니다.
  4. 4. 리뷰/보고서relevant, excluded, report set을 명확히 남깁니다.
