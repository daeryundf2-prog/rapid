# 콘솔 용어 사전 (console-glossary)

기준: `docs/plans/console-redesign-2026-10-10.md` §4.5. 한국어 전용 카피를 원칙으로 하며, 아래 표의 라벨만 사용한다.

| 선택 안 됨 | 파티션·범주 등이 선택되지 않은 상태 | 증거 카드(파티션), 처리 제한 사항(선택 안 된 범주) | 선택 기록 없음, category-not-selected |

- 화면 글자에 런 ID 원문을 두지 않는다: 런 이름·모드로 부르고, ID는 이름의 도움말과 "런 ID 복사" 동작으로만 노출한다. 증거의 런은 "이 런"·"런 n"으로 부른다.
- 단계·수집기 원문 ID(`artifacts-recent-files`, `fingerprint` 등)는 한국어 이름(아티팩트 수집: 최근 파일·LNK, 증거 지문(해시))으로 보이고 원문은 도움말에만 둔다. 모드는 원문 괄호 없이 "문서·부정 조사"처럼 쓴다.

## 그리드 열·범위 표시 (R7 S1 갈래 L2)

| 한국어 라벨 | 뜻 | 나타나는 곳 | 금지 동의어 |
|---|---|---|---|
| 검토 | 행의 리뷰 상태(관련 있음·재검토·제외·보고서 포함)를 보여 주는 열 이름 | 파일·문서·아티팩트·타임라인·지표 그리드 | 선별(열 이름으로), 리뷰 |
| 범위 | 지표의 분류 값(공인·내부망 등) 열 이름 | 지표(IOC) 그리드 | 분류, 선별 |
| 불러온 N / 전체 M | 서버가 가진 행 M 중 그리드가 불러온 행 N (전체를 아직 세지 못했으면 "전체 미확인") | 조건 줄 뱃지(목록형 그리드에 항상) | 로드됨, n건 로딩 |
| 정렬·필터는 불러온 행 기준 | 서버가 정렬·필터하지 못하는 열·조건이 불러온 행에만 적용됐다는 알림 | 그리드 위 배너 | 부분 정렬, 페이지 정렬 |
| 전체 정렬 | 서버가 목록 전체를 정렬한 상태("정렬: 크기 내림차순 (전체 N건)") | 그리드 정렬 상태 줄 | 서버 정렬, 인덱스 정렬 |
| 불러온 행만 정렬합니다 | 전체 정렬을 지원하지 않는 열 머리의 도움말 | 열 머리 도움말 | 정렬 불가 |
| 값이 없어 숨김 | 불러온 어느 행에도 값이 없어 기본 열에서 빠진 열(열 설정에서 다시 표시) | 열 설정 | 빈 열, 숨은 열 |
| 더 보기 | 통합 보기 표에서 200개씩 더 보여 주는 동작 | 통합 보기 | 더보기, 펼치기 |

- 파일 목록의 이름·경로·크기·수정·NTFS 생성·특이사항 열과 검색어 필터는 서버가 목록 전체에서 처리한다. 그 밖의 열 정렬·필터는 불러온 행에만 적용되고 배너가 그렇게 말한다.
- 시각 열 머리는 시각 종류를 이름에 담는다("마지막 방문", "수정"). 칩은 행의 시각 종류가 열과 다를 때만 붙는다.
- 경로는 끝(파일 이름 + 상위 폴더 2개)을 먼저 보이고 앞부분을 "…"로 줄인다. 전체 경로는 도움말에 있다.

## 사용 원칙

- "선별"은 상태 집합 이름으로만 쓴다. 증거·키워드·파일을 고르는 행위를 가리킬 때는 "선택"을 쓴다.
- 리뷰 상태 값은 네 가지(관련 있음·재검토·제외·보고서 포함)만 존재하며, 새 상태를 임의로 추가하지 않는다.
- 영문 라벨(예: Credentials, Web activity)은 화면 카피에 두지 않는다. 고유명사·포맷 약어(IOC, E01, MFT, USN 등)만 예외다.
