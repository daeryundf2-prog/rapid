# 콘솔 용어 사전 (console-glossary)

기준: `docs/plans/console-redesign-2026-10-10.md` §4.5. 한국어 전용 카피를 원칙으로 하며, 아래 표의 라벨만 사용한다.
금지 동의어는 같은 개념을 다른 말로 부르는 표현이므로 화면·문서·코드 주석 어디에서도 쓰지 않는다.

## 탐색 트리 노드

| 한국어 라벨 | 뜻 | 나타나는 곳 | 금지 동의어 |
|---|---|---|---|
| 접수 | 런 요약·진행·이슈를 모은 런 시작 노드 | 트리 노드, 런 개요 화면 | 인입, 인테이크, 수집 현황 |
| 검색 | 키워드·필터 질의와 최근 결과 | 트리 노드, 검색 결과 그리드 | 탐색, 서치, 쿼리 결과 |
| 파일 | 파일·미디어 항목 목록 | 트리 노드, 그리드 | 파일 목록, 파일 아이템, 파일 선별 |
| 문서 | 문서·메일 항목 목록 | 트리 노드, 그리드 | 도큐먼트, 문서 선별, 메일 선별 |
| 아티팩트 | 유형별로 나뉜 분석 산출 항목(하위 노드에 건수 표시) | 트리 노드, 아티팩트 그리드, 상세 패널 | 아터팩트, 증거 선별, artifact 등 외래 표기 |

## 접수 대시보드 (r7 검사관 우선 재설계)

| 한국어 라벨 | 뜻 | 나타나는 곳 | 금지 동의어 |
|---|---|---|---|
| 처리 상태 | 런의 처리 결과 건수·출력 폴더와 접힌 "단계 상세"(단계 표·수집기 표·검증 이슈) | 접수 카드 | 케이스 처리 세부, 스캔 세부 |
| 처리 요약 보기 | 산출물(처리 요약) 화면으로 가는 동작 | 접수 상태 줄 | 스캔 요약 보기 |
| 처리 설정 보기 | 런에 고정된 처리 옵션을 처리 단계에서 보는 동작 | 접수 상태 줄 | 설정 스냅숏 보기 |
| 스냅샷 | 런 시작 시 고정한 처리 옵션 기록 | 처리 설정, 케이스 연결 | 스냅숏, snapshot |
| 수집기 | 아티팩트 계열 하나를 모으는 처리 단위(진행 표의 행) | 처리 상태 "단계 상세" | provider, 프로바이더 |
| 처리 경고·알림 | 처리 중 기록된 경고(경고·오류)와 알림(경고 아님)을 사유별로 묶은 목록 | 처리 경고·제한 사항 카드 | 처리 문제, 공개 사항 경고 |
| 처리 제한 사항 | 이 런이 하지 못했거나 전수로 하지 못한 것(누락 도구·상한·절단·시간대 등) | 처리 경고·제한 사항 카드, 처리 단계 머리 | 공개 사항, disclosures |
| 확인 필요 사항 | 처리 제한 사항 중 결과 해석에 영향을 주는 줄(경고 톤) | 처리 경고·제한 사항 카드 | 경고 공개 사항 |
| 공개 사항(정보) | 처리 제한 사항 중 참고용 정보 줄(접힌 하위 절) | 처리 경고·제한 사항 카드 | — |
| 검사관 | 사건·메모·요약 노트를 쓴 사람(한 칸) | 사건 정보, 노트·메모 | 검사자, 작성자, 분석관(사람을 가리킬 때) |
| 해시 미검증 | 증거 해시를 아직 계산·대조하지 않은 상태 | 증거 카드 | 해시 검증 안 함 |
| 선택 안 됨 | 파티션·범주 등이 선택되지 않은 상태 | 증거 카드(파티션), 처리 제한 사항(선택 안 된 범주) | 선택 기록 없음, category-not-selected |
| 런 시작 | 증거 하나로 새 런을 시작하는 동작 | 증거 카드 | 런 추가 |
| 이력 n건 | 메모 작성·삭제 이력 수(삭제가 있으면 "· 삭제 n건") | 노트·메모 | 이력 보기 (n건 · 삭제 0건) |
| 알려진 정상(known-good) | 알려진 정상 파일 해시 목록과 그 숨김 옵션(첫 언급만 영문 병기) | 처리 설정 | known-good 단독 표기 |
| UTC±hh:mm | 증거 시스템 시간대 오프셋 표기 | 처리 제한 사항(시간대), 상태 막대 | bias -540분, UTC +09:00(띄어쓰기) |

- 화면 글자에 런 ID 원문을 두지 않는다: 런 이름·모드로 부르고, ID는 이름의 도움말과 "런 ID 복사" 동작으로만 노출한다. 증거의 런은 "이 런"·"런 n"으로 부른다.
- 단계·수집기 원문 ID(`artifacts-recent-files`, `fingerprint` 등)는 한국어 이름(아티팩트 수집: 최근 파일·LNK, 증거 지문(해시))으로 보이고 원문은 도움말에만 둔다. 모드는 원문 괄호 없이 "문서·부정 조사"처럼 쓴다.

## 사용 원칙

- "선별"은 상태 집합 이름으로만 쓴다. 증거·키워드·파일을 고르는 행위를 가리킬 때는 "선택"을 쓴다.
- 리뷰 상태 값은 네 가지(관련 있음·재검토·제외·보고서 포함)만 존재하며, 새 상태를 임의로 추가하지 않는다.
- 영문 라벨(예: Credentials, Web activity)은 화면 카피에 두지 않는다. 고유명사·포맷 약어(IOC, E01, MFT, USN 등)만 예외다.

## R7 단계 1 L4 — 쓰기 확인·셸·뷰어·탐색기·검토

| 한국어 라벨 | 뜻 | 나타나는 곳 | 금지 동의어 |
|---|---|---|---|
| 쓰는 위치 | 쓰기 동작이 파일을 만드는 경로(런 폴더 등). 확인 전에는 아무것도 쓰지 않는다 | 쓰기 확인 대화상자, 보고서 내보내기 | 저장 위치(다운로드 폴더와 혼동) |
| 새 런… | 케이스가 열린 상태에서 런을 하나 더 시작하는 상단 바 버튼(케이스에 연결된 런이면 "이 케이스에 런 추가") | 상단 바 | 실행(케이스 열린 상태), 빠른 런 |
| 케이스 없이 빠른 런 | 케이스에 묶지 않는 런. 런이 열린 상태에서는 "새 런 (케이스 없이, 열린 런과 별도)" | 실행 대화상자 | — |
| 패널 | 스테이지 레일 아래의 왼쪽 패널 접기/펼치기 토글("왼쪽 패널 접기") | 스테이지 레일 | 탐색(토글 이름으로) |
| 특이사항 A / 특이사항 B 이상 | 검토 단계 안의 특이사항 목록(탐색으로 넘어가지 않음) | 검토 왼쪽 패널 | 특이사항 B 이상 보기 |
| 하위 폴더 | 폴더 탐색기 가운데 위 칸: 열린 폴더의 하위 폴더(파일 수·하위 폴더 수·크기), 두 번 클릭·Enter로 들어감 | 파일 시스템 탐색기 | — |
| 바로가기 | 접수 왼쪽 패널: 증거·처리 상태·처리 문제 카드와 런 목록(처리 단계)으로 가는 링크 | 접수 왼쪽 패널 | 탐색 트리(접수에서) |
| 카드 N/M 준비됨 | 접수 카드 중 데이터를 받은 카드 수 | 접수 머리 | — |
| 세부 처리 n개 · 항상 실행 | 처리 그룹의 태스크 수 · 건너뛸 수 없는 그룹 | 실행 대화상자·마법사 처리 그룹 | (태스크 n), 필수 |
| 리뷰 상태 ▾ | 뷰어 머리의 리뷰 상태 칩 하나와 그 메뉴(관련·재검토·제외·보고서 포함·북마크) | 뷰어 머리 | 관련 있음 버튼 + 상태 칩(둘) |
| 태그 전파 | ⋯ 메뉴의 "같은 해시 행에 태그 전파" 한 항목(+기본과 다를 때만 태그별 항목) | 뷰어 ⋯ 메뉴 | 같은 해시 행에 전파(절 이름) |

- 쓰기 동작(샘플 실행, 검증 패키지·보고서·리뷰어 번들·제출 매니페스트 내보내기, 통합 보기 다시 만들기, 처리 그룹·태스크 건너뛰기·취소)은 모두 확인 대화상자(무엇을 어디에)를 먼저 띄우고, 끝나면 경로가 적힌 완료 알림을 띄운다. 검증 패키지 알림의 "열기"는 저장된 파일을 다시 읽기만 한다(다시 쓰지 않음).
- 뷰어의 시각은 초까지, UTC 병기에는 날짜를 붙인다("UTC 2025-05-29 14:25:26"). 초 미만(µs·100 ns)은 마우스를 올렸을 때 도움말에 보인다.
- 케이스가 없을 때 명령 팔레트는 "이동:" 명령을 숨기고, 비활성 이유는 "케이스를 먼저 선택하세요" 하나로 쓴다.
