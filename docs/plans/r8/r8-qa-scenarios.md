# R8 부록 E — 실데이터 검증 체계와 QA 시나리오 (QA-001 ~ QA-105)

마스터 7·8절. 원칙: **기능은 실데이터 콘솔 E2E(행 > 0)를 통과해야 "완료"다**(IS-121). 합성·단위 테스트만 통과한 것은 추적표에 "구현됨·실데이터 미검증"으로 남고 릴리스 노트에 그대로 적는다. 이 문서의 실데이터 수치는 엔지니어링 기준선이며 릴리스 증거가 아니다(AGENTS.md).
