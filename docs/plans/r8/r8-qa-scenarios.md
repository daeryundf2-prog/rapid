## E.3 QA 시나리오

열: **데이터** / **절차** / **기대(수치)** / **판정** / **증거** / **자동화**(PW = Playwright 스펙, PY = 파이썬 스크립트·테스트, 수동). 공통 전제: 서버는 QA 전용 포트·`--no-browser`·상태 복사본, 브라우저 1440×900(따로 적지 않으면), ko-KR·KST, 시작 전 증거 해시 기록.

〔2차 리뷰가 더한 공통 규칙〕
- **판정 열이 "—"인 시나리오**: 기대 열에 쉼표로 나열한 조건 **전부**를 충족하면 통과, 하나라도 미충족이면 실패다. 부분 통과는 없다. 수치는 반올림하지 않는다(마스터 9.2).
- **데이터 열의 C2·C3**: 승인(D24·D32)이 없으면 E.7 표의 대체 코퍼스로 실행하고, 추적표에는 "통과(대체 코퍼스: 이름)"로 적는다. E.7이 "미검증"이라고 한 시나리오만 미검증으로 남길 수 있다.
- **증거 위치**: `D:\rapid-qa\derived\r8\w{물결}\QA-xxx\` 아래 `result.json`(판정·수치·코퍼스·커밋·실행 시각+오프셋), `shots\NN-설명.png`, `net.har` 또는 `requests.jsonl`, `console.log`, 스펙 이름. 저장소에는 건수만(`docs/research/r8-wave-N-results.md`).
- **스펙 위치**: PW 스펙은 `frontend/e2e/r8/<이름>.spec.ts`(과제 e2e는 `frontend/e2e/tasks/`), 실행은 `cd frontend && npm run e2e -- e2e/r8/<이름>.spec.ts`. 실데이터 주소·처리 ID는 `R8_BASE_URL`·`R8_RUN_C1`·`R8_RUN_C2`·`R8_RUN_C3`·`R8_RUN_C4`·`R8_RUN_S` 환경 변수로 받고, 없으면 SYN으로 실행한다(건너뛰지 않는다 — GAP-057).
- **모호했던 시나리오의 전제·단계·판정 상세**는 E.9에 있다(QA-012·029·036·042·051~055·063·067·068·073·080·084·085·087~090·097·099).
