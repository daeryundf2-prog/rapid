## C.1 설계 원칙 (우선순위 순)

1. **틀리게 읽히지 않는다.** 건수는 잘리지 않고, 정의가 다른 수는 이름이 다르며, 0건은 사유를 말한다. (IS-005·014·029)
2. **사건 언어 먼저, 엔진 언어는 접어서.** 원시 키·파서명·처리 ID는 "기술 정보" 안에만. (IS-002·021)
3. **색은 판단에만.** 크롬은 무채색. 색이 보이면 처리 상태·포렌식 상태·등급·검토 판단 중 하나다. (IS-105)
4. **화면당 주 버튼 하나, 누르면 본문이 바뀐다.** (IS-013·109)
5. **숨긴 것은 숫자로 말한다.** 전문가 항목·필터·처리 제한. (IS-035·072)
6. **쓰기 전에 말한다.** "누르기 전에는 아무것도 쓰지 않습니다 / 원본 증거는 바꾸지 않습니다"는 유지. (IS-067)
7. **검사관의 손을 바꾸지 않는다.** 기존 단축키·주소 단어·딥링크·팝아웃·전문가 트리 순서 유지. (IS-011·015·039)
8. 〔v3〕 **화면은 하나다. 역할은 기본값만 바꾼다.** (IS-018)
9. 〔v3〕 **읽는 화면은 읽기 좋게, 훑는 화면은 훑기 좋게.** 둘을 섞지 않는다. (IS-129)

## C.2 목표 IA (v3)

```
상단바 48  [R RapidTriage] [사건명 · 증거 표시명 ▾]   [ 검색: 문서·대화·파일  / ]  [Ctrl K] [검토자|분석 담당] [⚙] [?]
```

| 레일 라벨 | 주소(불변) | 키(불변) | 구 라벨 | 하위 주소(신규는 굵게) |
|---|---|---|---|---|
| 사건 | `intake` | Alt+1 | 접수 | 쿼리 **`?share=1`**(화면 공유용 보기) |
| 처리 | `process[/kind]` | Alt+2 | 처리 | 탭: 처리 이력 · 처리 요약(옛 대시보드) · 더 분석하기 · 산출물(`report/outputs`가 이 탭을 연다) |
| 살펴보기 | `explore/{view}` | Alt+3 | 탐색 | 기존 9개 + **`explore/day`** · **`explore/people`** · **`explore/ai`** |
| 검토 | `review/board[/status]`, `review/flags` | Alt+4 | 검토 | **`review/set/{id}`** · **`review/one/{setId}/{n}`** |
| 보고서 | `report/outputs` | Alt+5 | 보고 | **`report/preview`**(기본 진입) |

- 주소의 단계 단어 다섯(`intake`·`process`·`explore`·`review`·`report`)은 **영구 정본**이다. `serializeRoute` 출력과 `canonicalizeHash`는 바꾸지 않는다. 주소 단어는 사용자에게 보이는 말이 아니다.
- 검토자 기본값에서는 레일에 "처리"가 없다. `Alt+2`나 주소로 열면 그대로 열리고 상단에 "분석 담당 화면입니다" 한 줄이 뜬다. 링크 공유는 막지 않는다.
- 역할 기본값이 바꾸는 것은 네 가지뿐이다: ① 레일의 "처리" ② 살펴보기 내비의 "전문가 항목" 펼침 ③ 밀도(검토자 32 / 분석 담당 28) ④ 뷰어의 헥스·SQLite 탭 노출. 주소·단축키·데이터는 같다. 브라우저별로 기억한다(`rapidtriage.v3.role`).
- 2년 방향(이번 범위 아님): 주소의 주어를 처리(run)에서 사건(case)으로 옮긴다. 새 주소는 추가하고 옛 주소는 영구 변환한다.

## C.3 화면 설계(와이어·구성 요소·상태)

모든 화면 공통 상태 5종: **로딩**(골격 1종, 300 ms 미만이면 표시 안 함) / **빈 상태**(사유+행동) / **오류**(무슨 일·영향·할 일 + 접힌 기술 정보) / **부분**(상단 호박 띠 "일부만 표시: 사유") / **숨김 고지**(목록 위 한 줄 "n건 숨김 — 사유별 · 모두 보기").

- 숫자는 전부 링크이고 눌러서 가는 목록의 건수와 같다(계약). 0건은 `ZeroReason` 10코드 중 하나. 값이 아직 없으면 "아직 계산하지 않았습니다"라고 쓴다(v0 단계에서 사용 기간·주요 프로그램이 여기에 해당).
- "화면 공유용 보기"(`?share=1`): 경로·계정명·호스트명을 `○○`로 가리고 레일·상태바를 숨긴 한 장. 인쇄(A4 1쪽)도 같은 모양.
- 지금의 접수 대시보드(단계표·예외 9범주·아티팩트 범주 막대)는 지우지 않고 처리 화면의 "처리 요약" 탭으로 옮긴다(T-224).
- v0(T-222)은 `/dashboard`·`/summary`·`/review-counts`만 쓴다. `/brief`(T-046)가 나오면 T-073이 데이터 출처만 바꾼다.
- 무결성 문구(〔2차〕 GAP-191): 승인(D34) 전에는 `컨테이너 해시 계산됨 · 매체 해시 미대조` / `컨테이너 해시 일치(입력값) · 매체 해시 미대조` / `컨테이너 해시가 입력값과 다름 — 매체 해시 미대조`(호박) / `해시 미계산`(호박) 넷만 쓴다. "검증됨"(초록 방패)과 빨강 "불일치"는 매체 해시를 대조한 뒤(T-125)에만 나온다. 단일 파일 증거(dd·raw)는 파일 해시 = 매체 해시이므로 일치/불일치를 그대로 쓴다.
- 구성 요소: `PageHeader`, `EvidenceStrip`(무결성 5표현 + 범위 띠), `FindingList`, `StatRow`(숫자+뜻+`>`), `ZeroReason`, `MiniTimeline`, `ReviewProgress`, `NextAction`, `Disclosure`(기술 정보).
- 내용은 `GET /api/runs/{id}/brief`와 1:1(부록 D.6). 색이 있는 곳은 방패·등급 배지·범위 띠뿐.
- "사용 기간"은 Tier 1 사용자 행위 이벤트의 최소·최대이고 ⓘ에 정의를 적는다. 폴더 증거(취득 사본 시각뿐)에서는 "산정 불가 — 사본 시각만 있음"(GAP-171).
- 상태: 처리 중(카드별 "처리 중" + 끝난 카드만 숫자), `/brief` 미계산(백그라운드 계산 중 n%), 케이스 미연결(머리줄 "사건 정보 없음 — 사건에 연결"), 다중 증거 "전체"(증거별 한 줄 비교 표: 건수·기간·범위·제한).
- 0건 사유 문구 사전(코드 → 문장 → 행동)은 v1 4.3 + `not_run`("아직 실행하지 않음 → 더 분석하기"), `partial_scope`("일부만 훑었습니다 — 처리 범위 보기").

## C.5 시각 언어

**타이포**: Pretendard(본문) + JetBrains Mono(경로·해시·오프셋·헥스만). 이탤릭 금지. `font-variant-numeric: tabular-nums`(지원 여부는 T-061에서 글꼴 파일로 검증, 미지원이면 숫자 열만 고정폭 글꼴).

## C.8 이행 전략(회귀 없이 바꾸는 순서) — 〔v3〕 v2 원문. 1·4·6·7·8번은 C.9.10으로 대체됐다

1. **계약 먼저**(부록 D): 주소·인용·단축키·접근성 이름·랜드마크·저장 키 표를 저장소에 넣고 계약 테스트로 고정. 그 뒤에 화면을 바꾼다. 〔v3〕 testid는 계약이 아니라 상수 모듈이다(D65).
2. **깨진 것부터**: 체크박스·메뉴 잘림·건수 잘림·글자 겹침·트리 공백·"알 수 없음초"·빈 상태 거짓말(물결 1). 구조 변경 전에 독립 수정.
3. **토큰·공용 컴포넌트를 추가 방식으로**: 새 토큰은 역할 이름(`--state-*`·`--forensic-*`·`--grade-*`·`--judgment-*`)으로 넣고(〔v3〕 `--r8-*` 같은 릴리스 이름 금지) 기존 토큰을 그 별칭에 연결 → 화면을 하나씩 새 컴포넌트로 옮김 → 옛 클래스 삭제는 마지막 물결. 한 PR에서 옛 것과 새 것을 동시에 지우지 않는다.
4. **새 셸은 감싸기**: 〔v3〕 레일 5개와 주소 단어는 그대로 두고 라벨만 바꾼다. 역할은 모드가 아니라 기본값이다(화면은 하나). 기존 e2e 13스펙은 분석 담당 기본값에서 계속 돈다.
5. **주소**: 새 주소는 추가, 옛 주소는 `canonicalizeHash`가 영구 변환(삭제 없음). 쿼리 키 30여 개는 그대로.
6. **저장 키**: 〔v3〕 일괄 이관은 하지 않는다. 새 키만 `rapidtriage.v3.*`를 쓰고 옛 키는 읽기만 하다가 그 기능을 고칠 때 옮긴다. 런별 누적 키는 LRU 20.
7. **문구**: 〔v3〕 소스 lint는 금지어 8개만 막고 나머지는 렌더된 글자 검사(`raw-values`)가 잡는다. 테스트가 고정한 문구(MetaView 40·CaseDashboard 30 등)는 접근성 이름 계약분만 남기고 나머지는 `copy.ts` 키로 옮긴 뒤 바꾼다.
8. **검증**: 물결마다 기존 e2e 13스펙(분석 담당 기본값) + 검토자 기본값에서의 과제 e2e + 실데이터 QA(부록 E). 〔v3〕 "모드"는 없다 — 같은 화면을 기본값 두 가지로 돈다.

## C.9 v3 추가 규격

### C.9.1 경로는 어디서나 증거 안 경로 (IS-128, D67)

- 목록의 "경로" 열, 뷰어의 "원본 경로", 인용, 보고서 모두 **볼륨 문자 기준의 증거 안 경로**다. 폴더만 보이고 앞을 한 번만 줄인다(가운데 줄임을 두 번 넣지 않는다).
- 추출 위치(분석 PC의 결과 폴더 경로)는 뷰어 "기술 정보"에만 "추출 위치"라는 이름으로 둔다.
- 삭제 복구본은 가짜 폴더(`_deleted_mft`)가 아니라 `복구` 표식 + "원래 위치 알 수 없음"으로 쓴다(엔진 물결 뒤에는 복원한 원래 경로 또는 "경로 불확실").
- 증거 안 경로를 주지 않는 수집기가 있으면 목록을 만들어 처리 소유자에게 넘긴다(T-171의 산출물).
- 파일 목록의 기본 첫 화면은 복구본이 아닌 할당 파일이다. 취득 사본 시각은 시계 표식 + "증거 시각 아님"(이탤릭 금지).

### C.9.2 제목·이름 (IS-126·127·002)

- 브라우저 탭 제목: `{화면} · {사건 표시명} — RapidTriage`. 처리 중이면 앞에 `(41%)`, 실패·부분이면 `(!)`.
- 제품 이름은 하나다(기본값 RapidTriage, D66). 워드마크·접근성 이름·보고서의 "도구 이름"·CLI `--version`이 같은 문자열을 쓴다.
- 표시 이름: 사건명 › 증거 표시명 › "이름 없는 증거 n". 폴더 약칭을 제목으로 쓰지 않는다.
- 모든 화면 공통 `PageHeader`: 제목 20px 한 개 + 한 줄 설명 + 건수 + 주 버튼 최대 1.

### C.9.3 읽기 표면 — 뷰어의 미리보기·대화·이메일 (IS-129)

### C.9.4 읽음 표시·구절 인용·알림·공유용 보기 (IS-130~133·137)

- **읽음 표시**: 한 번 연 항목은 주 열 글자 굵기가 500 → 400으로 내려간다. 판단 표식과 별개다. 브라우저 저장소에 처리별로 기억한다(서버·증거·케이스 DB에 쓰지 않음).
- **구절 인용**: 본문을 끌어 선택 → "인용 복사": 기존 인용 문자열 + 끝에 `구절="…"`. 기존 키 이름·순서 불변(부록 D.2).
- **처리 종료 알림**: 탭 제목 변경 + 브리핑 상단 한 줄. OS 알림은 설정에서 켠 사람만(D69).
- **다른 사람의 표시**: 30초마다 검토 건수만 조용히 비교한다. 다르면 목록 위에 "다른 사람이 3건을 표시했습니다 — 새로 고침". 자동으로 화면을 바꾸지 않는다.
- **화면 공유용 보기**: C.3 (2) 참조.
- **검토 묶음**: 머리에 "2026-11-11 만든 묶음 · 120건 · 출처: 검색 `계좌`". 질의를 다시 돌려 생긴 차이는 "새로 맞는 항목 3건 — 묶음에 추가". 부분 결과 검색에서 만든 묶음은 "검색이 일부 결과였음"을 머리에 남긴다(IS-149).
- **한 건 보기**: 1440 미만에서는 판단을 아래 고정 막대(56px: 관련 R · 재검토 I · 제외 X · 보고서 P · 태그 · 메모 · 41/120)로 내리고 본문이 뷰어 전체 폭을 쓴다. 판단 직후 다음 미검토로 자동 이동(설정에서 끌 수 있음).
- **하루 보기**: 날짜를 고르지 않고 열면 "기록이 있는 마지막 날"을 연다. 전체 타임라인의 기본 정렬은 최근순이다.
- **메뉴**: 행 메뉴 = 뷰어 ⋯ 메뉴 = 8개(열기·관련 있음·제외·태그·보고서 포함·전후 5분·같은 파일의 다른 흔적·더 보기). 쓸 수 없는 항목은 넣지 않는다.
- **팔레트**: 실행 가능한 명령만. 범주 이동은 "이동:" 접두 입력 때만.

### C.9.11 v3 리뷰 추가 규격 (2026-11-12)

- **읽기 전용 띠**(IS-175, T-348): 읽기 전용 결과를 열면 상단 진행 띠 자리에 한 줄 — "읽기 전용 결과 — 결과 폴더가 증거 안에 있습니다" / "읽기 전용 서버" / "보관된 사건". 색은 처리 상태 계열의 중립(빨강 아님), 모양은 자물쇠 글리프 + 글자. 쓰기 컨트롤은 숨기지 않고 비활성 + 같은 사유(왜 안 되는지 보여야 한다). 1280×720에서 띠 높이 28px, 브리핑 스크롤 0을 깨지 않는다.
- **검토자 링크**(IS-174, T-351): 상단 우측 "검토자 링크 복사" → 팝오버에 가린 주소(`…#token=••••`)와 "복사" 한 버튼, 아래에 "서버를 다시 켜도 이 링크는 유효합니다 / 폐기하려면 `web --rotate-token`" 한 줄. 토큰 원문은 화면에 그리지 않는다.
- **용어**(IS-179, T-361): `?` 도움말에 "단축키 · 용어" 두 탭. 용어 탭은 검색 입력 + 목록(용어 · 한 줄 뜻 · 옛 이름). "바뀐 이름" 카드는 브리핑 위에 한 번, 닫으면 다시 뜨지 않는다.
- **사건 보관·삭제**(IS-180, T-360, D73): 사건 목록의 항목 메뉴에 "보관" / "삭제…". 삭제 대화상자는 위험 스타일 + 기본 포커스 "취소" + 사건 이름 입력 + "보고서 판과 감사 기록도 함께 삭제" 체크(기본 해제) + 결과 문장("증거 파일은 지우지 않습니다").
