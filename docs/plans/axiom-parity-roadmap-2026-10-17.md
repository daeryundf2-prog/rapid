## 1. 사람에게 가장 효율적인 구성 — 설계 규칙(모든 라운드에 적용)
검사관의 질문 순서가 화면 순서다. 한 질문에 한 화면, 다음 행동은 두 번 클릭(또는 단축키 1회) 안에.

| 질문 | 단계(레일) | 첫 진입 화면 | 효율 규칙 |
|---|---|---|---|
| 무슨 사건이고 증거가 뭔가 | 접수 | 케이스 카드(사건·증거·처리 설정·처리 문제·메모) | 케이스 만들기 3단계 ≤ 2분, 증거 추가는 드래그/경로 붙여넣기, 처리 문제는 사유별 1줄 |
| 뭘 돌렸고 뭐가 남았나 | 처리 | 처리 계획표(그룹→태스크, 상태·건수·소요) | 그룹 단위 취소·재실행, 추가 분석 카드 "결과 보기 →" 1클릭 |
| 누가·무엇이·어디서 나오나 | 탐색 | **통합 보기**(사람·장치·경로·첨부·자격 증명·URL)가 첫 노드, 그다음 계열 트리 | 값 클릭 → 원본 행, 트리 검색·빈 계열 숨김, 혼합 격자 2줄 셀, 단일 계열은 카탈로그 열 |
| 뭐가 이상한가 | 탐색 › 특이사항 | 등급 A→B→C, 규칙별 노드 | 근거 팝오버에 출처 링크·오탐 주의, `sort=flags` 기본 |
| 무엇을 남길 것인가 | 검토 | 태그별 노드·메모·리뷰보드 | 태그 단축키 1–9, 해시 전파 1명령, 창 모드 뷰어로 듀얼 모니터 |
| 어떻게 제출하나 | 보고 | 보고서·번들·CSV | 모든 행에 소스·위치·복구 방법·증거 번호·사건 번호·파서 버전 자동, 인용은 `규칙@버전` 포함 |

AXIOM이 못 한 것은 재현하지 않는다: 이름 없는 버튼, 셀 값이 안 읽히는 격자, 셀 단위 Tab, 영문 순 한국어 정렬, 상태 전환 공백, 대표 값만 있는 제목, 비정상 시각 무경고.

## 2. 라운드

### R2 — 커뮤니케이션·유출 경로 (갭 1·2·3·5·6)
한국 기업·법무 사건의 1순위 증거. AXIOM 대비 "부분"을 "있음"으로.
1. **Windows 데스크톱 메신저 공급자** `windows-messenger`: Teams·Slack·Discord·Telegram Desktop·WhatsApp Desktop·Skype·LINE PC·WeChat PC·Zoom — `artifacts/mobile/messengers.py`의 채팅 프로필을 `AppData\Roaming|Local\<app>` 경로 서명으로 재사용. 행 유형 `chat-message|chat-attachment|chat-contact`, 메신저 계열 카탈로그 열(대화방·발화자·방향·첨부·삭제).
2. **카카오톡 PC 메시지 본문·공유 사진·첨부**: 기존 `kakaotalk-decrypt` 결과를 런 단계에서 `kakaotalk-message` 행으로 연결(키 재료가 있을 때만; 없으면 "복호 키 없음" 사유). 공유 사진 캐시 → `kakaotalk-shared-picture`.
3. **브라우저 심화**: Chromium 캐시 항목 디코딩(`browser-cache-entry`: URL·헤더·본문 해시·크기), 레거시 Edge/IE `WebCacheV01.dat` 컨테이너 행(`ese_native.py`), Opera·Whale 프로필 경로, 웹메일(Naver·Daum·Gmail) 첨부 업로드 페이지 복원 후보.
4. **클라우드 동기화 클라이언트**: OneDrive SyncEngine·로그, Dropbox, Google Drive DriveFS 전량, 네이버 MYBOX → 계정·동기화 폴더·업로드/삭제 이벤트 열; 규칙 `cloud.bulk_upload`.
5. **Outlook PST/OST·ICS**: 외부 파서 래퍼 출력을 `email-message|calendar-event|contact|email-attachment` 행으로 정규화, `/doctor`에 도구 유무.
완료 기준: 커뮤니케이션 그룹 있음 ≥ 30/54, 각 공급자 픽스처 + 실데이터 1건 이상, 통합 보기 사람·첨부 표에 반영.

### R3 — 운영체제 심화·안티 포렌식·파일시스템 (갭 7·8·9·10·11·12)
1. 레지스트리 분류 추가: NetworkList Profiles/Signatures, MountPoints2·Map Network Drive MRU, WLAN 이력, Office File/Place MRU, Known DLLs, Default Browser, PCA, FeatureUsage, Application Install States.
2. Prefetch 완전 디코딩(MAM 해제·실행 시각 8개·볼륨 테이블) → `execution.runcount_spike` 활성.
3. 안티 포렌식·암호화 도구 흔적 규칙 `antiforensics.tool_present`(출처 명시 목록) + BitLocker 복구 키 파일 파서.
4. NTFS 타임스탬프 불일치 노드·SI/FN 8열 표, $LogFile 트랜잭션 후보.
5. 이벤트 로그 채널 서브노드(네트워킹·Office Alerts·스토리지·사용자 PNP·스크립트·서비스·방화벽).
6. 카빙 시그니처 확장(오디오·Office/HWP·이메일·PE) + 카빙 결과를 `recovery_method=carved` 행으로 계열 노드에 통합.
완료 기준: 운영체제 그룹 있음 ≥ 45/49, P3 파서 깊이 문서 갱신.
