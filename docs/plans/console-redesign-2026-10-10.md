# 분석 콘솔 UI/UX/AX 재설계 계획 (console-redesign)

날짜: 2026-10-10 · 브랜치(예정): `ux/console-redesign` · 선행: `perf/run-pipeline-mitigations` (PR #2)
역할: 계획·난제·검증 = Fable, 주 구현 = Opus, 워커 = Sonnet, 잡일 = Haiku. 병렬 실행(스트림 S1–S6).

근거 인벤토리(2026-10-10, 읽기 전용 조사): v1 컨트롤 전수 조사, v1/v2 아키텍처 평가. 아래 "현재" 열의 `file:line`은 그 조사 결과다.

## 1. 최종 사용자와 과업

**포렌식 분석관 A.** E01을 넣고 하룻밤 뒤 돌아온다. 그 다음 하루 종일 하는 일은 단 네 가지의 반복이다:

1. **찾기** — 키워드/유형/시간으로 행을 좁힌다.
2. **보기** — 행을 고르면 **원본이 바로 옆에** 보인다(텍스트·헥스·SQLite·이미지·문서·메타/해시).
3. **표시** — 관련 있음/재검토/제외/보고서 포함, 태그, 메모. 키 하나로.
4. **내보내기** — 선별한 것만 추출·인용·보고서.

A는 하루에 수백 번 "행 선택 → 원본 확인 → 표시"를 반복한다. 이 루프에서 **마우스 이동 거리, 클릭 수, 눈의 이동(어디를 봐야 하나)**이 곧 생산성이다. A는 버튼을 눌렀는데 아무 일도 안 일어나면 도구를 불신하기 시작하고, 같은 곳으로 가는 길이 14개면 어느 것이 "진짜"인지 매번 고민한다.

## 4. 결정: 기반과 정보 구조

**기반 = v2(React/Vite)에 새 셸을 만들고 v1 패널을 기능 단위로 이식·대체한다 (C안).** 이유: (1) React는 기본 이스케이프라 `innerHTML` 79곳의 XSS 표면이 사라진다, (2) v2 토큰·3분할·가상 테이블·타입 스키마가 이미 있다, (3) v1 리팩터(A)는 9.7k줄 단일 파일을 영구 기반으로 남긴다. 번들은 커밋(U11). v1은 `/legacy`로 이동해 동등성 확인 전까지 유지, 이후 삭제.

### 4.4 접근성 사양 (U9)

- 랜드마크: `banner`(상단바) · `navigation`(트리) · `main`(그리드) · `complementary`(뷰어) · `contentinfo`(상태바) · 스킵 링크 → `main`(`tabindex=-1`).
- 그리드: `role=grid`, 행 `role=row` + `aria-selected`, 로빙 `tabindex`, `aria-rowcount`/`aria-rowindex`(가상), 정렬 `aria-sort`, 결과 수 `aria-live=polite` 단일 문장.
- 트리: `role=tree/treeitem`, `aria-expanded`, `aria-level`.
- 뷰어: `role=region aria-label="원본 뷰어"`, 모드 `role=tablist` + 화살표, 로드 시 제목으로 포커스 이동(`Enter`로 열었을 때만), 로딩 `aria-busy`.
- 모든 아이콘 버튼 `aria-label`; 툴팁은 `aria-describedby`; 비활성 이유는 툴팁 + `aria-disabled` 유지(포커스 가능).
- 대비: 토큰 조합 전수 검사 스크립트(`frontend/scripts/check-contrast.mjs`, WCAG 공식) CI 게이트 ≥ 4.5:1 본문, ≥ 3:1 큰 글자/UI 경계.
- `prefers-reduced-motion` 시 애니메이션 0; `prefers-color-scheme` 기본, 사용자 선택 우선.
- 키보드만으로 시나리오 Q-A1(§7) 완주.

### 4.5 디자인 토큰·용어

- v2 `tokens.css`를 단일 출처로: 색 ≤ 40, accent 하나(결정: v2 블루 `#4d9fff` 유지 — 대비 검증 통과 쪽), 밀도 3단(24/28/32) UI 토글.
- 아이콘: 인라인 SVG 세트 ~40개(`frontend/src/icons/`), 외부 의존 없음.
- 글꼴: Pretendard 등 시스템 폴백 유지(번들 금지 — 오프라인·라이선스).
- 용어 사전(`docs/console-glossary.md`): 접수/검색/파일/문서/아티팩트/타임라인/IOC/리뷰/산출물; 리뷰 상태 = 관련 있음·재검토·제외·보고서 포함; "선별"은 상태 집합의 이름으로만.
