# 콘솔 시각 품질 라운드 — "고급스럽지 않다"를 고치기 (2026-10-12)

사용자 피드백: v1·v2 모두 "허접하다 / 고급스럽지 않다". 기준점: 마에스트로 WISDOM·AXIOM Examine의 전문가용 다크 콘솔(어두운 슬레이트 면, 촘촘한 리본, 균일한 컨트롤 높이, 또렷한 위계).
전제: P1(`feat/analysis-workbench-p1`) 통합 후 같은 브랜치 또는 후속 브랜치 `ux/visual-polish`에서 진행(CSS 파일 충돌 방지). 기능·a11y 계약은 그대로, 대비 게이트(4.5:1 / 3:1)는 유지.

## 1. 현재 화면에서 싸구려 느낌을 만드는 원인(스크린샷 `docs/screenshots/console-2026-10-11/*` 기준)

1. **글꼴**: Pretendard가 토큰에만 있고 번들되지 않아 Windows에서 맑은 고딕으로 떨어진다. 숫자가 등폭이 아니라 표 열이 들쭉날쭉하다.
2. **브라우저 기본 컨트롤**: `<select>` 15곳, `date/datetime-local` 입력, 체크박스가 OS 기본 모양 그대로라 테마와 따로 논다.
3. **필터 바 4줄**: 서로 다른 높이·너비의 버튼·입력·칩이 네 줄로 펼쳐져 화면 윗부분이 산만하다(계획 §9-C 백로그였음).
4. **버튼 과다·동일 가중치**: 뷰어 툴바 11개, 배치 바 8개가 모두 테두리 있는 같은 모양이라 어디를 눌러야 하는지 위계가 없다.
5. **면·선 구분 없음**: 트리·그리드·뷰어가 같은 밝기의 면 위에 1px 회색 선으로만 나뉜다. 선택 행은 연한 파랑 덩어리, 포커스는 얇은 점선.
6. **아이콘**: 선 굵기·크기가 제각각(이모지 ⋯, 텍스트 ▲▼, 인라인 SVG 혼재).
7. **빈 상태·랜딩**: "케이스를 먼저 선택하세요" 한 줄과 테두리 버튼 두 개. 제품 첫인상이 없다.
8. **밀도 리듬 부재**: 8px 격자가 지켜지지 않는 곳(툴바 14px, 셀 6px, 패널 10px)이 많다.
9. **라이트 테마가 기본으로 보임**: OS가 라이트면 라이트로 뜬다. 포렌식 콘솔은 다크가 기본이어야 하고 라이트는 선택이다.

## 2. 목표 상태

- **U-V1 다크 우선 "Forensic Slate"**: 기본 다크(OS 설정과 무관, 사용자가 라이트를 고르면 저장), 면 4단계(`surface-0` 앱 배경 → `surface-3` 팝오버), 선 2단계, 텍스트 3단계, 액센트 1 + 상태 5. 토큰 수 유지(≤40).
- **U-V2 타이포**: Pretendard Variable + JetBrains Mono Variable을 **로컬 번들**(npm 패키지, CDN 없음), `font-variant-numeric: tabular-nums`, 크기 11/12/13/14/16/20 유지, 행간 1.4, 제목 letter-spacing −0.01em.
- **U-V3 컨트롤 체계**: 높이 28(기본)/32(여유), 반경 6, 입력·셀렉트·날짜·체크박스·라디오를 자체 스타일(네이티브 요소 유지 + CSS appearance 제거 + 커스텀 화살표/달력 아이콘). 버튼 변형 4종(primary / secondary / ghost / danger)과 아이콘 버튼 32px. 세그먼트 컨트롤(열/썸네일/대화/히스토그램, 뷰어 모드 탭).
- **U-V4 레이아웃 리듬**: 상단 바 48px 한 줄(브랜드 · 케이스 · 전역 검색 · 명령 · 우측 액션), 필터 바 **한 줄 칩**(검색어 입력 + "필터" 팝오버에 시간·유형·상태·태그·확장자·경로; 적용된 조건만 칩으로), 그리드 헤더 32px 고정·행 구분 1px `line-subtle`·선택 행은 좌측 2px 액센트 바 + `surface-2`, 트리 섹션 제목은 11px 대문자 간격 + 우측 등폭 배지, 뷰어 툴바는 1차(원본/헥스/메타) + 더보기 메뉴, 배치 바는 primary 1개(관련 있음) + secondary.
- **U-V5 아이콘**: 단일 세트(Lucide 계열 16px, stroke 1.75) 인라인 SVG로 교체, 텍스트 화살표·이모지 제거(⋯ → 아이콘).
- **U-V6 빈 상태·랜딩**: 케이스 없음 = 중앙 카드(브랜드 마크, "케이스 열기 / 이미지 실행 / 샘플" 3버튼, 최근 케이스 목록, 단축키 힌트), 그리드/뷰어 빈 상태는 아이콘 + 한 문장 + 다음 행동 버튼.
- **U-V7 상태 표현**: 리뷰 상태 칩은 색점 + 텍스트(테두리 버튼 아님), 진행률은 얇은 바 + 퍼센트, 알림(notice)은 우하단 토스트 1종.
- **U-V8 모션**: 120 ms ease-out, 팝오버 fade+2px, 포커스 링 2px 액센트(outline-offset 1px).
