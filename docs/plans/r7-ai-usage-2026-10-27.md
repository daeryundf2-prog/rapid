# R7 단계 3.5 — AI 사용 기록 분석 (2026-10-27)

입력: `docs/ai-tool-catalog/` (카탈로그 JSON 7개, `GAP_ANALYSIS.md`, `PC_SURVEY.md`). 사용자 요청: "AI 사용 기록에 대한 분석 기능을 추가해라". 계획 Fable → 구현 Opus(갈래별 워크트리) → 워커 Sonnet → 적대적 리뷰 Fable. 절차·제약은 `r7-master-2026-10-26.md` §1을 따른다.

## 1. 목표

검사관이 한 PC(또는 이미지·폴더)에서 **어떤 AI 도구가, 어느 계정으로, 언제, 어느 프로젝트에서, 무엇을 시켰고(명령·파일·MCP), 무엇을 만들었는지**를 아티팩트·타임라인·통합 보기·보고서로 본다. 로컬 증거가 없을 때는 "서버 측 증거 필요"를 보고서에 명시해 "증거 없음 = 미사용"으로 오해되지 않게 한다.

이상 상태(사용자 시나리오):
- S1 퇴사자 유출 의심: Claude Code·Cursor 세션에서 `tool_use` 명령에 사건 폴더·USB 경로가 등장 → 파일 접촉 행 → 파일 목록과 연결 → 특이사항 B.
- S2 업무용 PC의 개인 계정 사용: claude-swap `sequence.json`·Claude 데스크톱 `claude-code-sessions\<계정>`·Chrome 프로필 11개 → 계정·프로필 단위 요약.
- S3 코드 저작권: Cursor `ai-code-tracking.db` `scored_commits`(AI/사람 라인 비율)·git 트레일러(`Co-Authored-By`) → 보고서 "AI 생성 코드 비율".
- S4 증거 인멸: 에이전트 도구 호출 `destructive=true`(ZCode `tool_usage`)·`rm`/`Remove-Item` 명령·Claude Code `.last-cleanup` → 타임라인 피벗.

공통 규칙:
- **자격 증명·비밀 값 수집·표시 금지**: 카탈로그 `credentials` 경로와 `secret:*`·`*token*`·`*oauth*`·`Cookies`는 `ai-credential-presence` 행(경로·크기·mtime·해시 없음)만. 본문·명령 문자열은 `redact_secret_text` + 단계 3 B 개체 마스킹(API 키 접두사 `sk-ant-`, `sk-proj-`, `AIza`, `hf_`, `ghp_`, `xai-` 등 → 해시+마스크)을 거친다. base64 이미지 블록은 존재·크기만.
- 상한: 세션당 메시지 2,000·메시지당 16 KB(초과는 `truncated`)·도구 호출 5,000·어댑터당 총 200 MB 읽기·SQLite 1 GB 초과는 메타 테이블만(사유 기록). 큰 DB(Cursor 399 MB, Antigravity 2.9 GB)는 **복사하지 않고 `immutable=1` 읽기** + 해시는 선택(`--hash-ai-dbs`).
- 휘발성 우선: `cleanupPeriodDays`·`.last-cleanup`·`retention` 메타를 행에 기록하고 접수 "처리 경고"에 "보존 기한 있는 AI 기록 N건".
- `coverage_status`: 카탈로그 `conf`·`local_verification` → `official|third-party|inferred|unverified|local-verified`; 어댑터가 실물 검증되지 않은 도구는 `schema-not-validated`.
- OS: 경로 규칙은 카탈로그 OS별(win/mac/linux); 파서는 공용. 이미지 입력에서는 사용자 프로필 루트(`Users/<u>`, `/home/<u>`, `/Users/<u>`) 전부 열거(계정별).
- 다중 계정·프로필: 행마다 `account_key`(도구 계정 폴더·Chrome 프로필·Windows 사용자)와 `profile_label`.

### 3.3 아티팩트 유형(`artifact_type`)과 필드
`ai-tool-presence`(tool, version, install_kind, path, mtime, account_key, retention, coverage) · `ai-agent-session`(tool, session_id, parent_session_id, account_key, cwd, project_label, git_branch/origin(가명 가능), model, started_at, ended_at, turns, messages, tool_calls, tokens_in/out, sandbox/permission_mode, title) · `ai-agent-message`(session_id, seq, role, ts, text(마스킹·상한), has_image, has_pasted, tool_use_count) · `ai-agent-tool-call`(session_id, ts, tool_name, kind(shell|read|write|edit|search|mcp|browser|other), target_path|command(마스킹), destructive, approval, exit_code, result_bytes) · `ai-agent-file-touch`(session_id, ts, op(read|write|edit|delete|create), path, exists_in_evidence, file_locator) · `ai-mcp-server`(tool, server, transport, command|url(마스킹), tools[], status, ts) · `ai-instruction-file`(tool, path, kind(CLAUDE.md|AGENTS.md|GEMINI.md|.cursorrules|MEMORY.md|rules), size, mtime, sha256, head_text) · `ai-credential-presence`(tool, path, size, mtime, kind) · `ai-account`(tool, account_key, org_label, email_domain, active, first_seen, last_seen, source) · `ai-code-attribution`(tool, file, commit, ai_lines, human_lines, ai_percent, model, ts) · `ai-usage-stat`(tool, period, model, tokens, requests, source) · `ai-model-file`(tool, path, size, format).

### 3.4 간접 증거(갈래 C, 백엔드)
- 실행 흔적: Prefetch/Amcache/SRUM/ShimCache 행의 실행 파일명을 카탈로그 `binaries`/`process_names`와 대조 → `ai-tool-presence(source=execution)`.
- 설치 흔적: npm 전역(`%APPDATA%/npm/node_modules`, `package.json`), pip site-packages, winget·MSIX 패키지명, VS Code/Cursor 확장 폴더(`~/.vscode/extensions`, `~/.cursor/extensions`) → `ai-tool-presence(source=install)`.
- 브라우저: 도메인 매칭을 카탈로그로 전환(이미 Stage 1에서 확인된 누락 z.ai·openrouter·devin·kiro·cursor·windsurf 포함), Chrome **프로필 전부** 열거 검증(`Profile N`), `last_visit_time=0` 처리.
- git 트레일러: 파일 인벤토리의 `.git` 저장소에서 `Co-Authored-By`·`Agent-Logs-Url`·`Generated with` 트레일러 커밋 수(저장소당 상한 5,000커밋, 읽기 전용 `git log` 대신 패킷 파싱 없이 `logs/HEAD`·loose objects 파싱? → 표준 라이브러리로 어려우면 `git` 바이너리 옵트인; 기본은 `.git/logs/HEAD` 메시지 줄만) → `ai-code-attribution(source=git-trailer)`.
- API 키 접두사: 단계 3 B `patterns.py`에 `api_key` 범주 추가(접두사+길이+문자집합, 값은 해시+마스크) → 검색 `apikey:*`.
- 통합 보기 표 `ai_usage`(도구×계정×일: 세션·턴·도구 호출·토큰·프로젝트 수)와 `ai_projects`(cwd/프로젝트 → 세션 수·접촉 파일 수·마지막 활동) — `derived/engine.py TABLES` 추가, 피벗 → 원본 행.
- 특이사항 규칙(카탈로그 YAML `ai.*`, 검증 메타 포함): `ai.credential_file_present`(C), `ai.destructive_tool_call`(B: destructive=true 또는 rm/del/Remove-Item/format 명령), `ai.evidence_path_in_tool_call`(B: 도구 호출 경로가 케이스 증거 범위·USB·클라우드 동기화 폴더), `ai.account_switch`(C), `ai.personal_account_on_corporate`(B: 계정 이메일 도메인 ≠ 조직 도메인, 사용자가 조직 도메인을 설정했을 때만), `ai.retention_cleanup_observed`(C), `ai.unknown_tool_candidate`(C), `ai.mcp_server_remote`(C: 원격 URL MCP).
- 보고서 절 `AI 사용`: 도구·계정·기간·세션 수·주요 프로젝트·도구 호출 상위·AI 생성 코드 비율·**갭 표**(도구별 "로컬 증거 있음/없음 → 필요한 서버 측 증거: 벤더 감사 로그·조직 관리자 내보내기·OAuth 승인 기록") ·수집 범위·동의 메타(케이스 마법사의 범위 필드 재사용). 한국 법령 문구는 넣지 않는다(법률 검토 대상, 자리만).
