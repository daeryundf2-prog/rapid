## 5. 백엔드 적대적 리뷰 체크리스트(B가 수정 중이던 항목)
- 409: `_active` 레지스트리로 판정, 취소는 `cancel_requested_at` 후 `_finish`에서 `cancelled`.
- 경로: UNC·`\\?\`·`\\.\`·상대·드라이브 상대·`~`를 파일시스템 호출 전에 거부, `abspath` 사전 검사 후 resolve 재검사(UNC는 50 ms 내 403).
- vsc-discover 결과도 `_confine`, 부모 탐색 깊이 1, 허용 루트 안만.
- NTFS 조인: 런당 볼륨 prefix 1회 결정(`ntfs_join.volume_prefix`, `partition`, `analysis_id`), 행별 strip 금지, 오탐 테스트.
- 조인 인덱스: 키별 single-flight, 런당 1개, 필드 최소화, USN 줄 바이트 검사로 건너뜀, 512 MB 초과 시 `status="too_large"`.
- 종료 훅: lifespan에서 취소 이벤트 set + `executor.shutdown(wait=False, cancel_futures=True)`, 데몬 스레드.
- 소수: 취소 체크 500엔트리마다; `after=` 음수 400; 재시작 복원은 owner pid/boot id/heartbeat; 터미널 상태 쓰기 재시도·폴백; 진행률 단조; 실행 중 `record_count`는 flush된 행만, StaleSortIndex 한국어; `find_ocr_result` failed 건너뛰고 이전 배치 폴백, 배치당 states 1회; `/files` output_dir 없을 때 조인 생략; `_analysis_row` 존재 검증; 잘못된 본문 422 한국어; `limit=0`+필터 400; `RAPIDTRIAGE_ANALYSIS_ROOTS` 따옴표 제거·상대 경로 경고.
- 문서: §3.3 노드 id `artifacts:<kind>:<type>`, 옵션/필드 추가, 트리 분석 노드 `latest`/`latest_completed`.
- 테스트 추가 목록: 취소→재제출, UNC/정션/`..`/env-root/디스커버 우회, 멀티 kind 스캔 상한 HTTP, MFT>2048 청크, USN 윈도 경계, ntfs-meta 2개(최신 우선·축출), 조인 오탐, OCR stale/failed, 손상 rows.jsonl, 진행률 단조, 정렬 캐시 키 고유성, 종료 훅; cross-case 공허 단언 교체.
