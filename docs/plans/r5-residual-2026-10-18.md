## 2. 결정
- 국내 사건 가치를 위해 AXIOM 밖 확장을 함께 한다: PotPlayer·곰플레이어(재생 기록), 네이버·카카오 지도 URL, EGG/ALZ, 국내 웹메일(네이버·다음·카카오).
- Google Analytics 쿠키(`__utma`, `__utmz`, `_ga`)는 인증 정보가 아니므로 파싱한다. 단 방문 시각·세션 수·유입 출처·검색어만 행에 넣고 클라이언트 ID 값은 저장하지 않는다.
- 비밀 값은 어떤 갈래에서도 추출하지 않는다: 지갑 키·시드, SSH 개인키, PuTTY/WinSCP 비밀번호, Signal/QQ 키, Credentials/Vault blob 내용, logins.json/key4.db 내용. 존재·위치·크기·시각만 낸다.

### L2 — 운영체제·시스템·정책 존재 (브랜치 `feat/r5-l2-os-system`)
- 새 행 유형 15개: 레지스트리 심화(`registry_depth.py`, 하이브·`.reg` 내보내기) `startup-item`(StartupApproved Run/Run32/StartupFolder, Run 값과 이름으로 연결), `registry-logon-banner`, `ssh-known-host`·`ssh-client-session`(PuTTY·WinSCP), `office-identity`, `desktop-wallpaper`(WallPaper·TranscodedImageCache·BackgroundHistoryPath). 파일 모듈 `artifacts/windows/system_extras.py`(`windows-system` kind에 붙임): `startup-item`(시작프로그램 폴더, 기존 LNK 파서), `ssh-known-host`/`ssh-authorized-key`/`ssh-client-session`/`ssh-key-file`/`ssh-server-config`(OpenSSH·ProgramData\ssh·WinSCP.ini·.ppk), `office-backstage-item`, `vm-config`, `crypto-wallet-presence`, `credential-store-presence`, `av-detection-log`(McAfee ENS·VirusScan), `desktop-wallpaper`(TranscodedWallpaper·CachedFiles). `windows-filesystem`에 `ntfs-volume-information`($Boot VBR + $MFT 3번 레코드; VSN 하위 4바이트는 LNK·Prefetch 표기와 같아 통합 보기 장치 식별자로 만남). LogMeIn은 기존 원격 제어 행(`product=logmein`). 이벤트 채널 그룹 `networking`(네트워크) + `evt-ch-networking`.
- 카탈로그 계열 15개(execution·registry·rdp·antiforensics·other·ntfs.yaml, 의미 태그 포함; `logon-banner`만 식별자 열 없음), `artifact_domains` 라우팅(시작 프로그램·배경·자격 증명 존재 → 운영체제, SSH → 연결 장치·원격, Office Backstage → 레지스트리, VM·지갑·백신 로그 → 안티 포렌식, 볼륨 정보 → 파일시스템), `domains.ts` 노드(os·registry·eventlog·devices·anti-forensics·filesystem 블록에 추가만), 타임라인 필드, 규칙 3개: `execution.startup_user_path`(B), `antiforensics.crypto_wallet_present`(C), `antiforensics.vm_present`(C).
- 비밀 비추출(Q-R5-2): 지갑 키·시드·xprv, SSH 개인키 본문, PuTTY/WinSCP 비밀번호 값, Credentials/Vault/Protect blob은 행에 들어가지 않는다. 같은 값이 다른 경로로 새지 않도록 하이브 문자열 피벗(`registry-hive-strings`)과 `.reg` 내보내기 행에서 PuTTY/WinSCP 비밀번호 값을 지우고, 문서 추출(docs 출력·색인·케이스 DB)은 지갑·자격 증명 저장소·SSH 개인키 파일 본문을 저장하지 않으며(개인키 블록·WinSCP.ini/.reg 비밀번호 줄은 가림) `--extract`는 같은 파일을 `secret-redacted`로 건너뛴다. 합성 픽스처 전체 런(`run_triage_mode`)의 모든 출력 파일에 심어 둔 비밀 14종이 UTF-8·UTF-16LE 어디에도 없음을 단언한다.
